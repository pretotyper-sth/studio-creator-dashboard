Q6크리에이터의 퍼블리시 전환율은 얼마나 되는가?

퍼블리싱 현황

퍼블리시한 유니크 크리에이터(1명이 10개 내도 1명) + 실제 퍼블리시 월드 수 · Published(배포 상태) / Update Required 구분 · Public≠Published

월별 신규 퍼블리시 월드 (상태별)

각 지점 = 해당 월 기준(마지막은 이번 달 부분 집계) · Published(배포 완료) vs Update Required(운영 일시중지·접속불가) vs 기타 · ※ Public은 Access Setting(별도 축)

퍼블리시 월드 상태 구성 (누적)

서비스 시작~현재 누적 · World Publishing/Version Status 기준. Published=배포 완료(접속 가능). Public(Access Setting)과 다름 · 상태값 문서

퍼블리시 월드 품질 티어 분포 (누적)

숫자가 낮을수록 상위 품질 (Tier0 최상)
Tier3: 방문 700+·D1 12%+·4분+ · Tier2: 2,000+·15%+·6분+ · Tier1: 5,000+·20%+·8분+ · Tier0: 10,000+·24%+·10분+

관측 대기(퍼블리시 30일 미만)는 아직 판단할 데이터가 없는 구간으로 품질 축 밖에 있습니다. 품질 순서는 그 다음부터 — 기준 미달 → Tier 3 → 2 → 1 → 0
기준 미달 = 30일이 지났는데도 Tier3 문턱을 넘지 못한 월드. 신규 여부와 무관한 성과 기준
관측 대기와 기준 미달의 비율 변화를 같이 보면, 퍼블리시가 활발한 것과 품질이 안 나오는 것을 구분할 수 있습니다

TTFP 중앙값 추이 (스튜디오 첫 로그인 → 첫 퍼블리시)

Time To First Publish · 코호트별 중앙값(일). 짧을수록 온보딩 효율
기산점은 게임 회원가입일이 아니라 스튜디오에 처음 들어온 날입니다. 가입 기준으로 재면 "스튜디오에 오기까지 걸린 기간"과 "와서 퍼블리시하기까지 걸린 기간"이 한 숫자에 섞여, 온보딩을 개선해도 지표가 안 움직입니다

Q7활동 크리에이터는 늘고 있는가? (유입 vs 이탈)

인 / 아웃 — 90일 활성 크리에이터 변화

매달 말일에 "최근 90일 안에 한 번이라도 편집한 크리에이터 명단"을 만들어 직전 달 명단과 비교합니다 (마지막 지점은 오늘 기준).
진입=지난 명단에 없다가 새로 들어온 사람 · 이탈=지난 명단에 있었지만 90일간 활동이 없어 빠진 사람 · 순증 = 진입 − 이탈

순증 (진입 > 이탈) 순감 (진입 < 이탈)

Q8퍼블리시 이후에도 크리에이터는 창작 활동을 지속하는가?

정착 리텐션 — 퍼블리시 후 다시 붙어서 작업

"어느 달에 처음 월드를 낸 크리에이터들이, 그 뒤 며칠 시점까지 스튜디오로 돌아와 합쳐서 N시간 이상 다시 작업했나"의 비율(%)

지속 작업률 (퍼블리시 후 1~30일)

첫 퍼블리시 후 1~30일 안에 동일 월드 v2+ 업데이트 또는 다른 월드 신규 퍼블리시한 비율. 퍼블리시 코호트별
같은 날(0일) 재퍼블리시는 "지속"이 아니라 같은 작업의 연장이라 제외합니다 — 코호트마다 이 문턱을 다르게 쓰면 앞 코호트가 실제보다 좋아 보입니다

이탈 후 복귀 크리에이터

마지막 스튜디오 로그인 30일+ 경과 후 재로그인한 크리에이터 (활성화 기준 재충족). 월별 복귀 수

Partner(외주) 계약자 정착률

계약 완료 후 30일 내 5시간+ 자발 재활동 · 후속 계약이 잡힌 기간은 제외 — 계약과 무관하게 플랫폼에 남는지를 봄

Q15만든 월드는 실제로 소비되고 있는가?

소비되는 월드 비율

한 달 동안 플레이어가 한 명이라도 들어온 월드 비율 · 막대 = 등재 월드 수와 그중 플레이된 월드, 꺾은선 = 비율
이 블록만 실측값 (2026-02 ~ 07-31 확정, fct_world_analytics) · 월드↔크리에이터 관계 매핑이 없어 세그먼트 분해 미지원이라 상단 필터와 무관하게 전체 기준

분모가 아직 'Live 월드'가 아닙니다. namespace='live'는 배포 채널 이름일 뿐 퍼블리시 상태가 아니고, 이 테이블은 한 번 등재된 월드에 방문이 0이어도 매일 행을 남깁니다. 지금 Live인 월드를 확정할 상태 메타(Published/Unpublished/Banned)가 없어 현재 분모는 등재 월드이며 이 비율은 잠정값입니다. 그래서 실측 스냅샷 페이지는 비율 대신 플레이된 월드의 절대 수를 싣습니다 — 상태 메타가 붙으면 이 비율이 대표 지표가 됩니다

월드당 월간 방문 중앙값

방문을 받은 월드만 대상 · 중앙값이라 히트작에 흔들리지 않음. 전형적인 월드가 받는 방문량

상위 10% 월드의 방문 점유율

한 번이라도 플레이된 월드 중 상위 10%가 전체 방문에서 차지하는 비중 · 높을수록 소수 히트작 의존

Q12Studio Agent는 실제로 쓰이는가? 문제없이 도는가?

Studio Agent 사용 크리에이터 비율 (90일)

Q16Agent를 쓰면 더 빨리 만들고, 만든 월드도 더 잘 되는가?

크리에이터 비교 — 더 빨리, 더 꾸준히 만드는가

최근 90일 활성 창작 크리에이터를 Agent 사용(AI CRUD 1회+) / 미사용 두 그룹으로 나눠 같은 기간 비교 · 상관관계 참고용(Agent 덕분이라고 단정할 수는 없음)
TTFP 비교는 Agent GA 이후 첫 퍼블리시한 사람만으로 한정합니다. GA 전에 이미 퍼블리시를 끝낸 고참이 미사용 그룹에 섞이면 그쪽 TTFP가 구조적으로 짧게 나와 비교가 무의미해집니다

월드 비교 — 품질과 실제 소비도 나은가

Live 퍼블리시 월드를 제작 중 Agent 사용(AI CRUD 1회+) / 미사용으로 나눠 비교 · 상관관계 참고용

제작 방식별 결과물 비교

퍼블리시 월드를 Agent 비중 = Agent 편집 턴 ÷ (Agent 턴 + 수동 편집 턴) 기준 5개 구간으로 나눠 완주·품질·소비·지속을 비교 · 아래쪽 비교는 양쪽을 모두 만든 크리에이터만 추려 숙련도 차이를 제거한 결과 · 상관관계 참고용
